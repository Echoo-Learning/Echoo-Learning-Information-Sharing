# Echoo Learning Information Sharing

忆可学境(Echoo Learning)云端英语学习系统 2.0 的**进展与待办**。公开可看,打开网页直接用。

- **公网地址:** https://echoo-learning.github.io/Echoo-Learning-Information-Sharing/
- **最新一份:** https://echoo-learning.github.io/Echoo-Learning-Information-Sharing/latest.html

## 怎么用

- 每次更新都**新生成一个页面**,文件名带日期和时间,例如 `2026-10-14_0225PDT_Echoo-Learning_进展与待办.html`,旧的不删。
- 页面里每一行进展都写明:**日期、时间、地点、谁做的、做了什么、凭什么说做成了**。
- 时间是 PDT(UTC-7);北京时间 = PDT + 15 小时。
- 首页按时间倒序列出所有历史版本。

## 目录

| 路径 | 内容 |
|---|---|
| `index.html` | 历史版本列表 |
| `latest.html` | 跳转到最新一份 |
| `reports/` | 每次更新的页面(文件名:`日期_时间PDT_Echoo-Learning_进展与待办.html`) |

## 说明

页面是公开的,不含密码、Key、邮箱和真实姓名。生成程序在私有仓库 `Echoo-Learning/Echoo_Learning` 的 `tools/progress/`。
